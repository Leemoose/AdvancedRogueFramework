# Potions

## Effect Types

### Status Effects
Temporary buffs/debuffs that persist over multiple turns (e.g., burning, poisoned, hasted, shielded).

### One-Time Effects
Instant permanent or semi-permanent changes (e.g., strength gain, armor change, max HP increase).

### Magic Effects
Special triggered abilities (e.g., teleport, invisibility, phase through walls).

## Application Targets

A potion's effect can be applied to:

- **Person** - affects the drinker/target directly
- **Tile** - affects a map tile (e.g., creates fire on ground, freezes water)
- **Weapon** - coats or enchants a weapon temporarily
- **Armor** - coats or enchants armor temporarily

## Usage Methods

- **Drink** - consume the potion for direct effect
- **Apply** - use on a weapon, armor, or tile

## Tag-to-Effect System

Potions have tags (from crafting ingredients). Tags determine which effects the potion produces.
